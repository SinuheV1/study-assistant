# Portfolio Framing

## Project Title
Local-First Autonomous Study Assistant with Modular LLM Backends

## One-Sentence Description
Built a modular retrieval-augmented AI system that runs locally, supports dynamic backend switching, and generates structured study materials with cost-aware API escalation.

## Technical Highlights
- Vector embeddings (MiniLM)
- Local LLM inference (Ollama)
- Modular provider abstraction (local / Claude / OpenAI)
- Retrieval scoring and thresholding
- Document ingestion pipeline
- Cost-aware routing logic

## Engineering Depth
- Tradeoff analysis
- Retrieval failure modes
- Chunking strategy evaluation
- Hybrid search exploration
- Confidence-based escalation

## Why It Matters
Demonstrates:
- MLE systems thinking
- Cost and performance awareness
- AI infrastructure design
- Responsible AI usage
