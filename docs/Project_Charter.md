# Project Charter
## Local Study Assistant – RAG + Agent Architecture

### Purpose
Build a local-first AI study assistant to support OMSA coursework and long-term growth toward Data Scientist / Machine Learning Engineer roles.

### Core Philosophy
- Local-first (privacy + cost control)
- Modular architecture
- Retrieval-augmented generation (RAG)
- Optional API escalation
- No hype automation
- Engineering discipline over convenience

### Long-Term Vision
A personal AI system that:
- Indexes textbooks, lectures, transcripts, notes
- Generates grounded study guides
- Produces practice problems
- Supports interview prep
- Evolves across semesters
- Demonstrates real MLE system design skills

### Success Criteria
- Fully local RAG pipeline working
- Modular LLM backend (local + optional API)
- Clean, portable project structure
- Documented design decisions
- Usable weekly during OMSA
